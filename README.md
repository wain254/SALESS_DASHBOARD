# Sales Performance Dashboard 📊

## Overview
This project automates Excel reporting using Python, demonstrating:
- Data analysis with pandas
- Excel automation with xlwings
- Professional report generation

## Features
- ✅ Generates sample sales data
- ✅ Calculates key business metrics (revenue, averages, trends)
- ✅ Creates multi-sheet Excel reports automatically
- ✅ Formats Excel output for professional presentation

## Tech Stack
- Python 3.14+
- pandas - Data manipulation
- xlwings - Excel integration
- openpyxl - Excel file handling
